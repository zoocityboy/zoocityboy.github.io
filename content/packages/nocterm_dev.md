Nocterm Dev is a VS Code extension focused on making terminal-centric development faster and more pleasant. It provides quick commands, handy snippets, terminal-aware shortcuts, and small quality-of-life tools that reduce context switching between editor and terminal.

Key features

- Command palette: Run common terminal tasks from the Command Palette.
- Quick terminal toggles: Open, focus, and navigate integrated terminals with shortcuts.
- Snippets: Useful boilerplate and terminal-oriented snippets for shell scripts and dotfiles.
- Lightweight UI: Minimal panels and notifications so the terminal stays the center of attention.
- Configurable keybindings and settings.

Install

Install from the Visual Studio Marketplace or run:

`code --install-extension zoocityboy.nocterm-dev`

Usage tips

- Use the Command Palette to discover commands like "Nocterm: Open Floating Terminal" or "Nocterm: Run Last Command".
- Bind terminal toggles to a single key for fast context switches.
- Enable snippets for your preferred shell in settings to get instant boilerplate.

Why use Nocterm Dev

- Reduce friction: Less switching between editor and terminal.
- Tailored for CLI-first workflows: Small, focused features that help when working with terminals and scripts.
- Lightweight: Designed to complement VS Code without overwhelming it.
